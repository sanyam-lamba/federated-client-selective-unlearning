Federated Client Unlearning in Medical Imaging

Implementation of a Federated Client Unlearning (FCU) framework with advanced sharding strategies for privacy-preserving machine unlearning in healthcare.

PyTorch DenseNet121 MedMNIST Federated Learning Python

Key Features

Model-Contrastive Unlearning (MCU)

Selectively forgets client contributions without retraining from scratch.

Frequency-Guided Memory Preservation (FGMP)

Preserves important model knowledge while erasing targeted data influence.

Shard-level Selective Forgetting

Fine-grained control over which data shards are unlearned per client.

Transform Benchmarks

Evaluated across FFT, DFT, DWT, and FWT frequency transforms.
